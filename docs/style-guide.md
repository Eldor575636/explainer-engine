# Style guide & prompt templates

## Gemini / image model: first message of a new chat (sets style for all scenes)

For every image in this chat, use this style: Vertical 9:16 frame for an explainer video. Bold graphic
editorial style: flat vector illustration with clean deep navy (#1B2A4A) linework and fills, off-white
cream paper background (#F4EEDF) with subtle halftone dot texture. Limited palette: cream, deep navy,
signal red (#C8102E) and mustard yellow (#D4A23A) only. High contrast, no gradients, not photorealistic.
Fill the entire background with a detailed related scene drawn in pale, washed-out navy at low opacity,
so there is no empty space, while the main subject stays bold and dominant in front. Red marks look like
a newspaper editor's hand-drawn pen. Leave the top 25% and bottom 20% of the frame calmer. Never include
any text, letters, numbers or labels. Reply 'ready' and wait for my scenes.

Then one short scene line per message. Save as 01, 02, … in order.

## Rules

- One chat per video so the style stays consistent; if it drifts: "redo, match the style exactly, no text".
- Check historical details in every scene line.
- Living politicians: recognisable but clearly stylized.
- Tested and approved: Democracy frame, Lincoln frame (face works in this style).

## v3: layered prompts (to try with Higgsfield)

For each scene generate separately:
1. **Background plate**: the place only, no main character, pale navy detail, room at top and bottom.
2. **Character**: the person/object alone, full body, on a plain flat cream background (easy cut-out),
   same style; consistent character via a reference image.
3. **Props** (optional): plane, ballot, flag… alone on plain background.
